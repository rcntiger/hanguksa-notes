주요 사건 흐름도

"~ 이후에 전개된 사실은?", "~ 사이의 시기에 있었던 사실은?", "~의 배경으로 옳은 것은?" 이 세 가지 유형은 개별 사실 암기가 아니라 사건의 인과관계를 알아야 풀립니다. 37개 전환점 사건을 원인 → 사건 → 결과로 압축했습니다.

고대
삼국~남북국
1. 백제의 흥망 전환점
근초고왕 전성기(371 평양성 공격)→ 장수왕 남진, 한성 함락(475, 개로왕 전사)→ 문주왕 웅진 천도
2. 나제동맹의 붕괴
나제동맹(백제·신라)→ 성왕, 관산성 전투에서 전사(554)→ 신라 진흥왕, 한강 유역 독점 + 나제동맹 파기
3. 백제·고구려의 멸망
대야성 함락(642, 김춘추 딸 사위 죽음)→ 김춘추, 당과 군사 동맹(나당연합, 648)→ 백제 멸망(660) → 백제부흥운동(복신·도침, 흑치상지) → 고구려 멸망(668)
황산벌 전투(계백)는 백제 멸망 직전, 백강 전투(왜의 지원군 패배)는 백제부흥운동 진압 과정입니다.
4. 삼국통일 완성
고구려 멸망(668) 후 당의 한반도 지배 야욕→ 나당전쟁(매소성·기벌포 전투)→ 삼국통일 완성(676)
5. 신문왕의 왕권 강화
김흠돌의 난(681, 진골 귀족 반란)→ 신문왕, 반란 진압 후 진골 귀족 세력 억제→ 관료전 지급·녹읍 폐지, 9주 5소경, 국학 설치
6. 신라 하대의 혼란
혜공왕 피살(780, 무열왕계 단절)→ 진골 귀족의 왕위 다툼 심화(김헌창의 난 등)→ 지방 호족·6두품 성장, 원종·애노의 난(889) 등 농민 봉기
7. 후삼국의 통일
견훤(후백제)·궁예(후고구려) 건국→ 견훤, 경애왕 죽임(포석정) → 공산전투 승리 → 고창전투 패배(930)→ 견훤 고려 귀부(935) → 신라 항복(경순왕) → 일리천 전투(936) → 고려의 통일
고려
건국~무신정권~대몽항쟁
8. 고려 초 왕권 강화
호족 연합 정권(태조, 흑창)→ 광종, 노비안검법·과거제(쌍기 건의)로 호족 견제→ 성종, 12목 설치 + 최승로 시무28조 수용 → 통치체제 정비
9. 거란의 침입과 격퇴
거란 1차 침입(서희의 외교 담판, 강동6주 획득)→ 강조의 정변(2차 침입 명분) → 거란 3차 침입→ 강감찬, 귀주대첩(1019) 대승
10. 문벌 사회의 동요
이자겸(외척)의 권력 독점→ 이자겸의 난(1126, 척준경과 결탁) 진압→ 묘청의 서경천도운동(칭제건원·금국정벌 주장) → 묘청의 난(1135, 김부식이 진압)
11. 무신정권의 성립
문벌 사회 모순 + 무신에 대한 차별→ 무신정변(1170, 정중부·이의방) → 경대승 → 이의민→ 최충헌 집권(1196) → 교정도감·도방 설치, 4대 60여 년 최씨 정권
12. 몽골 항쟁
몽골 1차 침입 → 살리타 사살(처인성, 김윤후)→ 최우, 강화도 천도(1232) → 장기 항쟁→ 개경 환도(1270) → 이에 반발한 삼별초 항쟁(강화도→진도→제주도)
13. 원간섭기의 종식
원간섭기(정동행성·응방·몽골풍)→ 공민왕, 기철 등 친원 세력 제거 + 쌍성총관부 수복(1356)→ 신진사대부 성장 → 이성계·정도전 등 여말선초 세력 형성
14. 고려에서 조선으로
우왕, 요동정벌 추진→ 이성계, 위화도회군(1388)→ 과전법(1391) → 조선 건국(1392)
조선 전기
건국~사화~왜란
15. 왕자의 난과 왕권 강화
정도전, 재상 중심 정치 지향(세자 이방석 지지)→ 제1차 왕자의 난(1398, 이방원이 정도전·이방석 제거)→ 태종 즉위 → 6조 직계제, 사병 폐지로 왕권 강화
16. 세조의 집권
단종의 어린 즉위→ 계유정난(1453, 수양대군이 정권 장악)→ 세조 즉위 → 6조 직계제 부활, 집현전 폐지, 직전법
17. 훈구와 사림의 충돌
김종직의 조의제문(세조의 왕위 계승 비판)→ 무오사화(1498) → 갑자사화(1504, 폐비 윤씨 사건)→ 중종반정(1506, 연산군 폐위) → 조광조의 개혁(현량과) → 기묘사화(1519)
18. 임진왜란의 전개
도요토미 히데요시의 조선 침입(1592)→ 신립 탄금대 패배 → 선조 의주 피란 → 이순신 해전 승리·의병 활약→ 훈련도감 설치, 명의 지원 → 정유재란(1597) → 왜군 철수(1598)
19. 호란과 북벌론
인조의 친명배금 정책→ 정묘호란(1627) → 병자호란(1636, 삼전도 항복)→ 청에 대한 복수심 → 효종의 북벌론(이완, 나선정벌 참여)
조선 후기
환국~세도정치
20. 예송에서 환국으로
자의대비 복상 문제 — 기해예송·갑인예송→ 경신환국·기사환국·갑술환국(붕당 간 정권 교체 반복)→ 붕당 폐해에 대한 반성 → 영조·정조의 탕평책(탕평비, 초계문신제)
21. 세도정치와 농민 봉기
신유박해(1801) 이후 세도정치 시작(안동 김씨 등)→ 삼정의 문란 → 홍경래의 난(1811) → 임술농민봉기(1862, 진주민란)→ 삼정이정청 설치(박규수 건의)
근대
흥선대원군~국권피탈
22. 통상수교거부와 양요
병인박해(1866, 천주교 탄압)→ 병인양요(1866, 프랑스·외규장각 약탈) → 오페르트 도굴사건(1868) → 제너럴셔먼호 사건→ 신미양요(1871, 미국·어재연) → 척화비 건립
23. 개항과 임오군란
운요호 사건(1875)→ 강화도조약(1876) → 개화정책(통리기무아문, 별기군) → 구식 군인 차별→ 임오군란(1882) → 제물포조약·청군 주둔 → 청의 내정간섭 심화
24. 갑신정변
청의 내정간섭에 대한 급진개화파의 불만→ 갑신정변(1884, 우정총국) → 청군 개입으로 3일 만에 실패→ 한성조약(조선-일본) + 톈진조약(청-일, 양국 군대 철수) → 훗날 청일전쟁의 빌미
25. 동학농민운동과 갑오개혁
고부 민란(조병갑의 탐학) → 안핵사 이용태의 탄압→ 1차 봉기(황토현·황룡촌 승리) → 전주화약·집강소 → 일본군 경복궁 침범→ 2차 봉기(우금치 패배) + 군국기무처의 갑오개혁(신분제 폐지 등)
26. 을미사변에서 대한제국으로
삼국간섭 이후 일본의 위기감→ 을미사변(1895, 명성황후 시해) → 을미개혁(단발령) → 아관파천(1896)→ 독립협회 활동(러시아 절영도 조차 저지) → 대한제국 수립(1897) → 광무개혁
27. 국권 피탈 5단계
러일전쟁에서 일본 승리→ 한일의정서(1904) → 을사늑약(1905, 외교권) → 헤이그특사 → 고종 강제 퇴위→ 정미7조약(1907, 군대 해산 → 정미의병) → 기유각서(1909) → 한일병합(1910)
이 5단계(한일의정서 → 을사늑약 → 정미7조약 → 기유각서 → 병합)의 사이 시기를 묻는 문제가 매 회 나옵니다 — 순서를 통째로 외우세요.
일제강점기
무단통치~광복
28. 3·1운동과 통치 방식 전환
무단통치(헌병경찰, 토지조사사업)에 대한 반발 + 고종의 인산일→ 3·1운동(1919) → 일제의 무력 탄압(제암리 학살 등)→ 대한민국임시정부 수립(상하이) + 일제의 문화통치로 전환(산미증식계획)
29. 대중운동의 확산
순종의 인산일(6·10만세운동, 1926)→ 민족주의·사회주의 세력 연합 → 신간회 창립(1927)→ 광주학생항일운동(1929) 발생 시 신간회가 진상조사단 파견
30. 무장독립전쟁의 전개
봉오동전투·청산리대첩(1920) 대승→ 일본의 보복 — 간도참변(1920) → 독립군 이동 중 자유시참변(1921)→ 3부(참의부·정의부·신민부) 성립 → 만주사변 이후 한중연합작전(한국독립군·조선혁명군)
31. 민족말살통치와 광복
중일전쟁(1937) → 침략전쟁 확대→ 국가총동원법(1938) → 민족말살통치(황국신민서사, 창씨개명, 공출)→ 일본 패망(1945.8.15) → 조선건국준비위원회(여운형)
현대
광복~오늘날
32. 정부 수립까지의 갈등
모스크바 3국 외상회의(신탁통치 결정) → 좌우 대립→ 미소공동위원회 결렬 → 좌우합작운동(여운형·김규식) 실패→ 유엔 총회의 남한 단독 선거 결정 → 5·10총선거(1948) → 대한민국 정부 수립
김구·김규식의 남북협상(1948.4)은 5·10총선거 직전에 있었던 단독정부 반대 시도입니다.
33. 6·25전쟁의 전개
북한의 남침(1950.6.25)→ 낙동강 방어선 → 인천상륙작전(9월, 서울 수복) → 중국군 개입 → 1·4후퇴→ 전선 고착 → 정전협정(1953) → 한미상호방위조약
34. 이승만 정권의 몰락
사사오입 개헌(1954)·독재 장기화→ 3·15 부정선거(1960) → 김주열 사망 → 4·19혁명→ 이승만 하야 → 허정 과도정부 → 장면 내각(내각책임제)
35. 유신체제의 성립과 붕괴
3선 개헌(1969) → 장기집권 시도→ 유신헌법(1972, 통일주체국민회의) → YH무역 사건 → 부마민주항쟁(1979)→ 10·26 사태(박정희 서거) → 신군부의 5·18 민주화운동 유혈 진압
36. 6월 민주항쟁
전두환 정부의 4·13 호헌조치→ 박종철 고문치사·이한열 사망 → 6월 민주항쟁(1987)→ 6·29 선언 → 9차 개헌(대통령 직선제, 5년 단임 — 현행 헌법)
37. 통일 정책의 흐름
냉전 완화 분위기(1970년대)→ 7·4남북공동성명(1972) → 남북기본합의서(1991, 노태우) → 남북 유엔 동시 가입→ 6·15공동선언(2000, 김대중) → 개성공단 → 10·4선언(2007, 노무현)
실제 기출 지문은 저작권상 옮기지 않았으며, 반복 출제되는 인과관계만 압축했습니다. 굵게 표시한 사건이 흐름의 중심축입니다. "~ 이후 사실"·"~ 사이 시기"·"~ 배경" 문제는 이 흐름 안에서 위치를 찾으면 풀립니다.
